# Off-Page SEO Checklist

Use this after publishing the portfolio changes. The goal is to build clear external signals around the same positioning used on the site: secure AI operations systems, agentic workflows, automation consulting, and Cognumi.

## Profile Links

- Add the portfolio URL to the GitHub profile bio and profile README.
- Add the portfolio URL to LinkedIn contact info, headline links, and featured section.
- Add the portfolio URL to X bio.
- Link Cognumi, agentalent.ai, ClipSpot, Lockey, and Bekon back to the portfolio where profile fields allow it.

## Article Distribution

- Share each new article on LinkedIn with a short original summary and canonical link back to the article.
- Add the most relevant article links to GitHub repository READMEs:
  - ClipSpot, Lockey, and Bekon should link to the macOS utilities article.
  - Cognumi-facing materials should link to the AI automation audit and safe AI workflows articles.
- Republish short excerpts only. Keep the full version canonical on the portfolio.

## Search Console

- Submit `https://rumi7911.github.io/portfolio/sitemap.xml` in Google Search Console.
- Submit the same sitemap in Bing Webmaster Tools.
- Inspect the homepage, writing page, and each new article after deployment.
- Request indexing for the highest-intent pages first: homepage, work page, AI automation audit article, and safe AI workflows article.

## Backlink Targets

- Ask clients, collaborators, and builder profiles to link to the portfolio using natural anchor text such as "AI operations consultant" or "secure AI workflow builder".
- Contribute guest posts or interviews on AI automation, agentic workflows, service business operations, and secure AI systems.
- Add the portfolio to reputable founder, builder, and developer directories where the profile is genuinely relevant.

## Measurement

- Track impressions for:
  - secure AI operations systems
  - AI automation consulting for service businesses
  - agentic workflows
  - AI operations consultant
  - secure AI workflows
- Review Search Console monthly and expand articles that receive impressions but low clicks.
